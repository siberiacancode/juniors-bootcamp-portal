## Создание проекта

<show when={props.stack === 'react'}>
Создайте проект на Vite с шаблоном `react-ts`.

```bash
npm create vite@latest pizza -- --template react-ts
```

</show>

<show when={props.stack === 'vue'}>
Создайте проект на Vite с шаблоном `vue-ts`.

```bash
npm create vite@latest pizza -- --template vue-ts
```

</show>

<show when={props.stack === 'angular'}>```bash npx @angular/cli new pizza ```</show>

<show when={props.stack === 'svelte'}>```bash npx sv create pizza ```</show>
