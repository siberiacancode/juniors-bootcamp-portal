# OrbitKit

OrbitKit - небольшой набор UI-компонентов для учебных проектов и прототипов. Он помогает быстро собрать аккуратный экран без лишней конфигурации.

Смотрите [репозиторий OrbitKit](https://github.com/example/orbitkit), если хотите изучить исходные примеры.

## Что есть в документации

- кнопки и ссылки;
- первый экран;
- настройка темы.

> OrbitKit подходит для небольших интерфейсов, где важны скорость и ясный API.
