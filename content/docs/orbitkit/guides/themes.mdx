#### Тема проекта

OrbitKit использует CSS-переменные, поэтому палитру можно поменять без переопределения компонентов.

```css
:root {
  --orbit-accent: #6d5dfc;
  --orbit-surface: #ffffff;
}

[data-theme='dark'] {
  --orbit-surface: #171717;
}
```

> Меняйте семантические переменные, а не цвета внутри отдельных компонентов.
