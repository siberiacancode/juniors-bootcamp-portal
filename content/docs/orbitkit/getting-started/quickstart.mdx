#### Первый экран

Создайте небольшой компонент с действием:

```tsx
import { OrbitButton } from '@orbitkit/ui';

export function Welcome() {
  return <OrbitButton>Начать</OrbitButton>;
}
```

1. Импортируйте компонент.
2. Передайте понятный текст действия.
3. Подключите компонент к нужному экрану.
