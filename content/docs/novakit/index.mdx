## Что такое NovaKit

NovaKit - это демонстрационная frontend-библиотека для SaaS-интерфейсов: админок, кабинетов, CRM, billing-панелей и внутренних инструментов. Она объединяет дизайн-токены, React-компоненты и рекомендации по доступности, чтобы команды быстрее собирали предсказуемые интерфейсы.

Библиотека не привязана к конкретному фреймворку рендеринга. Примеры в документации используют React и TypeScript, а пакет импортируется как `@novakit/react`.

### Основная идея

NovaKit исходит из того, что продуктовые интерфейсы должны быть плотными, понятными и устойчивыми к изменениям данных. Компоненты проектируются composition-first: вместо больших монолитов используются небольшие части с явными props.

> Демо-контент предназначен для проверки sidebar, MDX-контента и правого TOC. Реального пакета NovaKit не существует.

## Для чего подходит

NovaKit хорошо ложится на приложения, где пользователи часто сравнивают данные, заполняют формы и работают с повторяющимися сценариями. Это не набор маркетинговых секций, а библиотека для рабочих экранов.

| Сценарий                  | Пример экрана                      | Подходящий раздел                         |

## Быстрый пример

Ниже пример карточки с действием. Он показывает типичный стиль API: короткие props, композиция и явные состояния.

```tsx
import { Button, Card } from '@novakit/react';

export function BillingCard() {
  return (
    <Card>
      <Card.Header title='План Pro' description='Команда до 25 участников' />
      <Card.Content>
        <p>Следующее списание: 12 августа</p>
      </Card.Content>
      <Card.Footer>
        <Button variant='primary'>Изменить план</Button>
      </Card.Footer>
    </Card>
  );
}
```

### Что видно в примере

- `Card` отвечает за структуру и отступы.
- `Button` отвечает за действие и состояние.
- Текст остаётся обычным HTML, чтобы не скрывать продуктовую семантику.
