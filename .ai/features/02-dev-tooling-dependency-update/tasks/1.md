# Задача 1 · Обновить зависимости и инструменты разработки портала

## Описание

Перевести Juniors Bootcamp Portal с Yarn на pnpm 11, обновить прямые зависимости до актуальных стабильных версий и заменить Prettier, Husky и nano-staged на Oxfmt и Lefthook. Локальная и контейнерная сборки используют `pnpm-lock.yaml`; интерфейс сохраняет прежний вид.

## Реализация

Создать `pnpm-workspace.yaml` для одного пакета с применимыми настройками из [reactuse](https://github.com/siberiacancode/reactuse/blob/main/pnpm-workspace.yaml): `publicHoistPattern`, `allowBuilds` и нужными исключениями `minimumReleaseAgeExclude`. Перевести команды, инструкции и Docker-сборку на pnpm, удалить `yarn.lock` и устаревшие Yarn-настройки. Поле `packageManager` в `package.json` не добавлять. Bun остаётся средой выполнения `sync-projects`.

Подключить общий конфиг `@siberiacancode/oxfmt` и пресет `@siberiacancode/lefthook`. В `pre-commit` заменить Prettier на Oxfmt, сохранив ESLint и последовательную обработку файлов, которые меняют обе команды. Штатный `commit-msg` оставить без настройки `.emoji`. Удалить конфигурацию и зависимости Prettier, Husky и nano-staged.

Локальная `cn` объединяет значения через `cn` из `@siberiacancode/reactuse` и разрешает конфликты классов через `twMerge`. Несовместимости после обновления пакетов устраняются в рамках этой задачи.

## Тестирование

- `pnpm install --frozen-lockfile`, проверка типов, ESLint, Oxfmt и `pnpm build` проходят.
- Docker-образ собирается с тем же lockfile; приложение запускается через `pnpm start`.
- `pre-commit` обрабатывает staged-файлы через Oxfmt и ESLint; `commit-msg` добавляет префикс `<ветка> <emoji>` ровно один раз.
- Компоненты с `cn` сохраняют ожидаемые классы и вид на узком и широком экранах в обеих темах.
