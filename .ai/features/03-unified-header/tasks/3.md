# Задача 3 · Окно поиска по заданиям и гайдам

## Описание

Кнопка в общем хедере открывает окно поиска из макета на любой странице портала. Поиск показывает реальные результаты Algolia из заданий и гайдов. Результат гайда открывает `/guides/<slug>` или найденный раздел; результат MDX задания открывает существующую страницу `/tasks/<id>`.

## Реализация

За основу берётся [поиск reactuse](https://github.com/siberiacancode/reactuse/blob/main/packages/newdocs/app/%28docs%29/_components/layout/function-header/components/Search/Search.tsx): клиент Algolia с публичным ключом, поисковый хук Fumadocs, диалог и список команд с управлением с клавиатуры. По возможности используются готовые компоненты UI kit; недостающие общие примитивы добавляются в kit. Внешний вид, мобильное состояние, группы результатов и подвал с названием и логотипом Algolia соответствуют `.ai/inputs/header-kit.zip`. Окно открывается кнопкой и `⌘K` / `Ctrl+K`; после закрытия фокус возвращается к элементу, из которого его открыли. Недавние переходы из поиска показываются при пустом запросе, если они есть. При отсутствии настроек Algolia отображается отдельное состояние недоступности поиска, без демонстрационных результатов и ложного сообщения об отсутствии совпадений.

## Тестирование

- На любой странице окно открывается кнопкой и сочетанием клавиш; фокус попадает в поле. Escape и клик по подложке закрывают окно с возвратом фокуса.
- При настроенной Algolia запрос находит заголовки и текст заданий и гайдов. Стрелки меняют выбранный результат, Enter открывает соответствующий `/tasks/<id>` или `/guides/<slug>`; для гайда открывается найденный раздел, если он указан в результате.
- Проверены состояния пустого запроса, загрузки, результатов, отсутствия совпадений и недоступной настройки. Недавние переходы появляются только после переходов из поиска.
- Окно сверено со скриншотами архива в обеих темах на десктопе и мобильном экране; подвал содержит название и логотип Algolia.
- Актуализированы поисковые проверки в `documentations/cases/лейаут/хедер.ts`.
