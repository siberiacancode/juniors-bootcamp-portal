# Задача 1 · Единый хедер: вёрстка и навигация

## Описание

Общий хедер отображается на всех страницах портала и повторяет макет из `.ai/inputs/header-kit.zip` в светлой и тёмной темах. На десктопе доступны меню «Задания», «Документация», «Open source», ссылка «Тестирование», GitHub и переключатель темы. На мобильном экране те же доступные направления собраны в листе под хедером. «Войти» остаётся скрытым. Кнопка поиска присутствует в вёрстке; окно и поиск по Algolia относятся к задаче № 3.

## Реализация

Существующий `Header` в корневом `app/layout.tsx` остаётся общим для всех разделов. По возможности используются готовые компоненты UI kit проекта; выпадающие меню строятся на Navigation Menu shadcn/ui с Base UI, который добавляется в kit. Десктопное и мобильное представления используют общие данные пунктов и действующие маршруты: `/tasks`, `/tasks/<id>`, `/guides`, `/qa`. «Магазин игр», «Скиллы» и «Архитектура» помечаются как недоступные без ложных ссылок. Внешние пункты используют действующие адреса из `LINKS`. Текущий раздел и задание определяются по маршруту. Переключение темы использует существующий `ThemeProvider`. Хедер поддерживает контейнер до 1280 px обычно и до 1440 px для `/tasks/<id>/docs/...`; сами страницы в задачу не входят.

## Тестирование

- На главной, `/tasks`, странице задания, `/guides` и `/qa` состав и порядок пунктов одинаковы; текущий раздел или задание выделены.
- Доступные пункты ведут на действующие маршруты или внешние адреса. Недоступные пункты имеют понятное оформление и `aria-disabled`, без перехода.
- Меню открываются кликом и с клавиатуры, закрываются по Escape, клику вне меню и переходу; состояние триггера отражает открытие.
- При ширине до 1100 px поиск показан круглой кнопкой; до 860 px видны логотип, поиск, тема и бургер. Мобильный лист прокручивается при нехватке высоты и закрывается после перехода, по Escape и клику вне листа.
- Вёрстка сверена со скриншотами архива при 1440, 1024 и 390 px в обеих темах; переключение темы сохраняет читаемость элементов.
- Актуализированы применимые проверки в `documentations/cases/лейаут/хедер.ts`; сборка проходит, метаданные страниц и Яндекс Метрика продолжают работать.
