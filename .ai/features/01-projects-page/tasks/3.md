# Задача 3 · Создать страницу `/projects` с галереей и ссылками

## Описание

Посетитель видит галерею решений в порядке каталога, может открыть копию кода и перейти к инструкции по добавлению проекта из верхней кнопки или нижнего баннера. Страница работает на разных ширинах и в обеих темах.

## Реализация

Страница Next.js читает сохранённый каталог из `public/projects/` без обращения к GitHub и передаёт данные галерее. На широком экране карточки образуют три masonry-колонки с порядком слева направо; на мобильном — одну колонку. Карточка показывает `@username`, `name` или название задания при пустом `name` начальной записи, иконку framework и, при наличии поля `preview`, локальный скриншот с осмысленным `alt`. Ссылка на код строится из `path` и ведёт к копии в `juniors-bootcamp-examples`. Карточка целиком не является ссылкой. Ссылка на код открывается в новой вкладке с доступным названием и безопасными атрибутами.

Обе CTA ведут на `CONTRIBUTING.md`. Переходы передаются через существующую Yandex Metrica после согласия пользователя: `project_code_click` с `username` и `task`, `project_contribute_click` с `placement: gallery | subfooter`. Для `/projects` задаются русскоязычные title и description; глобальный `noindex, nofollow` удаляется с сохранением Open Graph-настроек. Текущие Header и общие цветовые токены используются без изменений. Страница разделена на HeroSection, GallerySection и SubfooterSection. Макеты служат источником оформления; маскот хранится в `public/illustrations/mascot/indiana-jones.webp`, а текстура баннера — в `public/images/textures/projects-subfooter.svg`. Обработчики аналитики стоят непосредственно на кнопках и ссылках; хуки `useGallerySection` и `useSubfooterSection` размещены рядом с одноимёнными секциями.

## Тестирование

- Карточки соответствуют порядку и данным сохранённого каталога; проверены варианты со скриншотом и без него, а также заголовок при пустом `name` начальной записи.
- Код и обе CTA ведут по нужным адресам; ссылки доступны с клавиатуры. Метрика получает согласованные события и параметры только после согласия.
- На широком экране галерея имеет три колонки с порядком слева направо, на мобильном — одну; промежуточная ширина не создаёт горизонтальный скролл. Страница читаема в обеих темах и соответствует переданным макетам.
- `/projects` имеет собственные title и description; глобальный `noindex, nofollow` отсутствует, Open Graph сохраняется. Открытие страницы не вызывает запросов к GitHub. Проверки соотносятся со случаями «Проекты» и «Галерея проектов» в `documentations/cases/проекты/`.
