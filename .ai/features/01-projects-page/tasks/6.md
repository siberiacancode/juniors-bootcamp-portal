# Задача 6 · Вынести карточку проекта в UI kit как compound-компонент

## Описание

Галерея `/projects` продолжает показывать те же данные и ссылки, используя составную карточку из UI kit.

## Реализация

`ProjectCard` становится набором именованных частей по принятому в UI kit образцу. UI kit отвечает за разметку и оформление карточки; `GallerySection` подставляет данные проекта, переводы, адреса ссылок и обработчики аналитики. Необязательный скриншот подключается при композиции без пустого элемента.

## Тестирование

- Проверить карточки со скриншотом и без него, а также отображение названия задания при пустом `name` начальной записи.
- Проверить порядок карточек, ссылки и их доступные названия, клики Метрики после согласия, мобильную и десктопную раскладку. Ориентир — существующие кейсы «Галерея проектов» в `documentations/cases/проекты/`.
